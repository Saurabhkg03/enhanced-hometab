# Changelog

## [1.0.0] - 2026-08-06

### Added
- **Initial Release** of the Enhanced Hometab Plugin!
- **Dashboard Engine**: Core component lifecycle management.
- **Widget Framework**: Modular widget registry.
- **Omni-bar Search**: High-performance fuzzy search with virtualized rendering.
- **Recent Notes Widget**: Instantly jump back into recently modified context.
- **Quick Actions Widget**: Fast shortcuts for common commands.
- **Tasks Widget**: Asynchronous parsing of recent notes for open checkboxes.
- **Settings Architecture**: Full settings pane to toggle widgets and customize greetings.
- **Layout Engine**: Native HTML5 drag-and-drop widget reordering with persistence.
- **Animations**: Staggered CSS hardware-accelerated animations for premium feel.
- **Performance Optimizations**: Async yielding (`requestIdleCallback`) to prevent main thread blocking in massive vaults.
